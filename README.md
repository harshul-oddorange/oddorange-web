# oddorange.co website

A static site: plain HTML, CSS and JavaScript, built with [Vite](https://vite.dev).
Motion uses GSAP (scroll animation), Lenis (smooth scroll) and Matter.js (the ball pit).

## Quick start

```bash
npm install
npm run dev      # local preview at http://127.0.0.1:5190
npm run build    # production files in dist/
npm run format   # tidy all code with Prettier
```

Needs Node.js 20 or newer.

## Where things live

```
index.html            Page structure: every section in order, with comments
terms.html            Terms of Service      (generated by scripts/build-legal.py)
privacy.html          Privacy Policy        (generated)
cookies.html          Cookie Notice         (generated)
refunds.html          Refund & Cancellation (generated)
404.html              Page-not-found
public/               Files copied as-is (favicon, share image, your photo)
netlify.toml          Hosting settings for Netlify

src/content.js        ALL editable content: prices, packages, process steps, videos, socials, email
src/main.js           Entry point: starts each module in order

src/lib/              Shared helpers
  dom.js              Selectors, colours, price formatting, canvas sizing
  pointer.js          Live mouse position
  icons.js            Social and UI icon paths

src/modules/          One file per feature
  intro.js            Logo animation on first visit
  cursor.js           Orange-dot cursor (desktop)
  nav.js              Header and mobile menu
  smoothScroll.js     Smooth scrolling and in-page links
  dotField.js         Interactive dots under the hero
  crateLine.js        Dotted separator with the rolling orange ball
  services.js         "What we make" cards
  work.js             Showreel and sample video slots
  videoSlot.js        YouTube embed (loads only when clicked)
  pricing.js          Pricing columns, comparison meters, ₹/$ toggle
  process.js          Process columns with scroll-linked progress
  scenes.js           Scroll animations (reveals, showreel, idea text, card fan)
  ballPit.js          Falling balls above the footer
  form.js             Enquiry form validation and sending
  contactLinks.js     Email links, social icons, year

src/styles/
  main.css            Imports every stylesheet below, in order
  tokens.css          Brand colours, type sizes, spacing (change values here)
  base.css            Reset and shared layout
  components/         Reusable pieces: buttons, labels, cursor, form, meters…
  sections/           One file per page section
```

CSS class names follow `block__element--modifier` (for example `package__price`, `btn--primary`).

## Common edits

- **Prices, package contents, process steps:** `SERVICES` in `src/content.js`.
- **Videos:** paste YouTube IDs into `VIDEOS` (showreel and "Fresh from the crate") or a package's `sample` in `SERVICES`.
  Use `kind: 'reel'` for vertical videos and `kind: 'motion'` for 16:9. Empty IDs show a "coming soon" slot.
  Add a `poster` for each video: a still saved in `public/img/work/` as .webp (1280×720 for 16:9, 720×1280 for Reels).
- **Social links, booking link, your LinkedIn:** `SITE` in `src/content.js`. Empty social links show greyed out with "soon".
- **Prices:** every package needs both `inr` and `usd`. The ₹ / $ switch updates both pricing columns,
  the "What we make" cards and the enquiry form's options.
- **Colours or type sizes:** `src/styles/tokens.css`.
- **Headlines and About text:** `index.html`.
- **Testimonials:** add entries to `TESTIMONIALS` in `src/content.js`; the section appears automatically. Real, approved quotes only.
- **Your photo:** replace `public/img/harshul.webp` (transparent background, about 820 px wide, head near the top).
- **Legal pages:** edit the text in `scripts/build-legal.py`, then run `python3 scripts/build-legal.py`. `TODO(...)` items show highlighted until filled in.

## Publish (Netlify, free plan)

1. Put this folder in a GitHub repository, then on Netlify choose "Add new site → Import from Git". `netlify.toml` already sets the build.
2. Netlify → Site settings → Forms: enable form detection and add an email notification to harshul@oddorange.co.
3. Netlify → Domain management: add `oddorange.co`, then add the DNS records Netlify shows in Wix → Domains → DNS.
   **Only change the website records (A / CNAME for `@` and `www`). Never change MX or TXT records: they run the Google email.**

## Privacy by design

The site loads nothing from other companies when a page opens: fonts are self-hosted, there is no analytics and no cookies.
YouTube loads only after a visitor presses play. If you add analytics later, you'll need a consent banner first.

## Before going live

- Fill every highlighted `TODO(...)` in `scripts/build-legal.py` (business form, address, GSTIN, court city) and re-run it.
- Have the legal pages reviewed; they are plain-language drafts, not legal advice.
